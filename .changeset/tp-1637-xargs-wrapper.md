Read xargs with no piped input and a dynamic word behind a wrapper as the push they may be. An unknown `-I` record fills every place its replace string appears with the worst case, so `xargs -I % git push origin %` reads as a protected push. A dynamic word that a wrapper reads as its positional or as the command word may expand to nothing, an option or another wrapper. The words are therefore also read without it, wrapper by wrapper up to the nesting limit, with the piped input still known: `timeout $O 5 git push` and `printf 'HEAD:main\n' | sudo $a xargs -I % git push origin %` now give a push verdict.
