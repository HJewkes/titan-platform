`GateAuthorize` takes an optional third argument `{ admittedBy }` ("owner-class", "allowance", "evidence" or "delegate") so an authorizer can tell how the store admitted a resolver; it still only narrows, and a two-argument authorize is unchanged. `openGate` accepts a `rule`, and `ctx.assisted` takes `rule?: GateRule` and stores it on the gate it opens (TP-3289).
