`shepherd release --class g10-review` now accepts a PR whose head is Shepherd's own clean merge-up of the reviewed head, as a `g10-adversary` release already did. Land's update-branch merges main into a held PR whenever it reads behind, so every main move used to reset the review bar on g10-review holds. A merge no update-branch step of the run recorded, or one whose tree is not the clean merge-tree of the reviewed head and its base parent, is still refused.
