Post-merge main CI makes fewer GitHub calls. Every live post-merge run on a repo now reads check runs through one shared per-repo ledger (`MainCiReads` in main-watch), so several runs on the same tip make one `checkRuns` per poll between them. `sh-main-ci` takes the base branch from the run's own merge, and `sh-cleanup` takes merged, head ref, head repo and merge sha from it. After Shepherd's own merge, neither step reads the PR. A PR merged outside the run, or a step recorded before these fields, still reads the PR as before.
