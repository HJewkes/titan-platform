The L1 item rubric tells the odd-one-out and kind-honest judges that an item the narration explicitly sets apart (a default that applies when nothing is chosen, "not X", "until", "except", an item that "goes" or "is removed") is the beat working as intended, not the odd one. The judge picks an item only if the beat presents it as parallel to the others and it is not. The rubric sha, and so the `L1-items` eval_version, changes.
