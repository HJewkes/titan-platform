The script stage now stamps `new_terms` on the first beat that speaks each spine-ledger handle, when the ledger defines the item in that beat's chapter and no beat of that chapter declares it. A stamp is kept only when the stage's own L0 lint then fails no error row, on any beat, that the script did not already fail, so a stamp never trips Q-E4, Q-F8, Q-W2, the pace counts or any other rule that reads `new_terms`. Each stamp is reported as a non-gating `ledger-stamp` check. The Q-E17 repair hint now names each ledger-unlisted item (a pin, reveal or card), its beat and the ledger handles that chapter may use, and names an item shown before the chapter that defines it.
