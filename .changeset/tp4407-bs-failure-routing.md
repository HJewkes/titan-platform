build-surface routes a red gate by its record's `failure.class`. `code`, and an absent or unrecognized class, goes to the fix round as before. `infra` probes the spec's optional `gate.health`, reruns the gates once, then parks on the owner gate `infra-park:<slice>`, and counts no fix round. `gate-broken` and `spec` stop the slice and file a task, one per failure signature as grouped by `@titan-design/cluster`, so a repeat finds the task already filed.
