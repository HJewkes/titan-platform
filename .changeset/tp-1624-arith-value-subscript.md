Check the command substitutions that arithmetic runs from inside a bracket of a variable's value: `X='a[$(git push origin HEAD:main)]'; (( X ))` now classifies the push.
Every value a variable takes is recorded where it is stored: assignments and appends, declarations, `printf -v`, prefix assignments, array elements and element writes, and, as unknown, what `read`, `mapfile`, `getopts`, a `for` or `select` list, `set` operands, a function's or a shell's arguments, a `${X:=...}` default or text built at run time store. Nothing is walked or refused unless the same line evaluates arithmetic: `(( ))`, `$(( ))`, `$[ ]`, `let`, a subscript, a substring offset (of a variable or of `$1`, `$@`, `$*`), an indirect expansion, a subscripted or run-time variable name handed to `read`, `printf -v` or a declaration, `declare -i` or `-n`, a numeric `[[` comparison, `unset`, a `-v` test, or a `$(( ))` in an unquoted heredoc.
On such a line, each known value that holds code behind a bracket has its substitutions classified, and the hook denies the line when one cannot be walked in full or when the line types code behind a bracket (in one word, a heredoc or a here-string, or split across them) and also stores text the check cannot follow. A PR body, a regex or prose that holds a bracket and inline code passes when nothing on the line evaluates arithmetic.
