Add per-file line-density metrics (TP-2474 k), written on every TypeScript and Python file, zeros included: `long_line_share_160` (share of non-blank lines longer than 160 characters), `chars_per_sloc` (characters per non-blank line, surrounding whitespace excluded) and `bool_ops_per_line` (`&&`, `||`, `??` and ternaries, or Python `and`, `or` and conditional expressions, per non-blank line). Operators are counted from the syntax tree, so text inside strings and comments never counts. `INDEX_VERSION` is now 0.28.0, so the first index after upgrading reparses every file.
