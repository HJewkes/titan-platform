The panel aggregate counts a vacuous fix-proof that `provedByMutants` proves as good, as Shepherd's fix-proof judge already did, so it no longer adds an unplanned blocking tests seat that left every round `no-verdict`. `PanelVerdict` gains `fixProofShortfall`, set when that unplanned tests seat is the only blocking member missing; when that proof is vacuous or test-less, Shepherd sends the head back as its own NO_REPRO instead of retrying a fresh reviewer, and an owner's waiver of it now clears the seat on a test-only head that proceeds.
