Add `rewriteScript`, the rewrite pass core for TP-3817. Each round plans register edits, makes one schema-bound call per directed chapter through an injected `JudgeHarness`, guards each beat, appends the labels for moved numbers, re-runs L0 and reverts any beat that gained an error row. A round is kept only when it fails no more target rows and comes closer to band. Round 2 works only on beats that still hold a triad or crowded numbers. A failed call leaves its chapter unchanged and is reported. Spoken numbers are spelled after the last round, and the report lists target rows before and after, rewritten, rejected and reverted beats, and spend per call.
