A question or design round now checks before it sends. Check and send opens a summary of every answer by section: the pick, the comment and option notes, each judged frame's verdict and comment, and the round feedback. Unanswered questions are marked; Show only unanswered filters to them, and Answer next unanswered closes the summary on that question's page. Esc goes back to answering and Cmd or Ctrl+Enter sends. Required questions no longer hold the send (owner decision 513): with any question unanswered the button reads "Send partial: N unanswered" and still sends. A revision request with no comment still holds it, since the server refuses one.
