Shepherd no longer counts a refused reviewer dispatch as a failed review round. When `sh-review` is refused for any reason other than a still-busy broker (for example `ReviewCheckoutUnusable` for a repo with no bound checkout), the run is held as `no-reviewer: <refusal> at <head>; TP-2446` and the seat is alerted once. The review is retried after a release or a head move, so three refusals no longer open a `failed-rounds` approve-merge gate on an unreviewed head. A refused step result now carries `refused: <failure class>`.
