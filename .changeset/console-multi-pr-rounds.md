A Ship round can carry one merge-bound question per PR (TP-3329). Each PR in its `prGroups` gets its own section in the Ship view: the PR's title, kind, task and description, the `changed` lines of its sections, its question frames, its own main-vs-head montages and side questions, and its own Ship or Send back with a Send back note. One "Send answers" press writes every answer to the round's single `feedback.json`, and stays off until each PR has Ship or Send back. `rounds.submit` takes `heads` (question id to head sha) and checks each shipped question against its own head, refusing a missing, wrong or extra head. Ship blockers are worked out per PR, so a comment on one PR's questions or its Send back note never holds another PR's Ship. `round import` takes several merge-bound questions only when each has its own PR group at the same head and is asked in one of that group's sections. A sent round's notes carry `picks`, so the page shows which PR shipped. A round with one Ship question behaves as before.
