`fix-proof exec --sandbox-user <name>` (and `ExecSideOptions.sandboxUser`) runs each base-side vitest call through `sudo -n` in a fresh PID namespace as that user, with `no_new_privs` and an empty capability bounding set, so no `setsid` child of a head test outlives the run to rewrite the base reports. The vitest output is read only as a regular non-symlink file, and a sandbox that cannot be set up writes error markers instead of running unsandboxed. The head side ignores the flag.
