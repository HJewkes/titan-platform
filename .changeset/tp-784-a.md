`titan-factory gate resolve` asks for owner presence in every shell (owner decision 2026-10-06, item 39). A shell with `AGENT_CHAT_AGENT_ID` unset or empty no longer resolves as `owner-terminal` without a dialog: with no presence proof it exits 1 with `owner presence not confirmed; the gate stays pending` and writes nothing. A confirmed dialog resolves as `owner-terminal` with the proof as `confirmEvent`. The coordinator stuck-behind allowance and the TP-1904 evidence path are unchanged and still need the agent-chat marker. On a host with no presence helper, a CLI resolve now always refuses.
