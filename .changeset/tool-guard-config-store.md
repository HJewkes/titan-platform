"@titan-design/tool-guard": patch

tool-guard guards the fleet config store as permission config (TP-3584). A write by any tool or shell form to the materialized coordinator document (`~/.config/titan-coordinator/` and `~/Library/Preferences/titan-coordinator/`), or to the console's owner state (`lan.token`, `owner-actions/` and `config/` under `~/.local/state/titan-console/`), now classifies as `authority-config`. So do `titan-console login-link` and `token rotate`, under the new spelling `bash.config.console-owner-auth`. They are matched as the console receives them: through any wrapper, with a quoted `"token rotate"` read as its two words, or as the console's CLI script under node or tsx, resolved from the command's directory. The spelling also covers `config import`, which seeds the store's first revision, ahead of the console verb that adds it; `config compare-tree`, which only reads, is left alone. Reads of the same paths, and the console's other verbs, still pass. The state directory itself is guarded by its exact path, so removing, moving or copying over it is refused while its inbox and rounds stay writable. A wrapper or runner option that starts the command in another directory (`env -C`, `sudo -D`, `pnpm --filter`/`-C`/`-r`, `npm --prefix`/`-w`, `yarn` and `bun --cwd`) now sets the command's `runDir`: the directory it names, or null when only known at run time. The command's arguments and any shell text it runs resolve from there, so `env -C <dir> sh -c '... > coordinator.json'` and a relative console script it runs are both matched. A hard link of a guarded config path (`ln` without `-s`, `cp -l`/`--link`) counts as a write of it. ln's `-s` counts only before its first operand and before `--`, so `ln -- doc -s` is a hard link and refused; and a node or tsx entry is resolved as node resolves it (`dist/cli` runs `dist/cli.js`), with a `-r`/`--require`/`--import` preload, eval text loading the CLI, or a stdin script read as running the console. A config write whose directory is only known at run time (`cd "$D"`, `$X/coordinator.json`, `$(echo ~)/...`) is matched by its literal tail and refused. A symbolic link made earlier on the line is followed by later commands, and one made at a path only known at run time to a guarded path is refused. Brace lists are expanded before matching, a globbed copy destination counts as any directory it matches, and `find <dir> -name <name>` with `-delete` or a writing `-exec` reaches a guarded file under `<dir>` by name. An unknown command word or runner script (`$C login-link`, `node $S token rotate`) followed by a literal owner verb reads as the console.
