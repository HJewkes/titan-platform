Shepherd's visual-path gate counts only files that can render (TP-2660 g). Tests and specs (`*.test.*`, `*.spec.*`), markdown (`*.md`) and type declarations (`*.d.ts`) under a seat's `visual_paths` no longer gate a merge. A rendering file beside them still gates, and the gate reason lists only that file. An empty or unread file list still counts as visual.
