`ciPolicyLabelledLines(text)` lists every labelled line a MERGE block's `ciPolicy` folds, each with its own reading, through the same reader `parseVerdictBlock` uses. The factory adds the read-only `gate.ownerEvidence` command (TP-4489, the first slice of TP-4404): the console card for an owner-at-head approve-merge gate is projected from the merge evidence the gate was opened on. Its facts are recomputed with land's own functions and must equal the gate's marker, unknown names included; a CI-policy section heads with the stored reading and shows the verdict text only when the shared reader still reads the same. A gate whose facts need file sections reads `missing` until they land.
