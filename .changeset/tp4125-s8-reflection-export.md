The export stage now lands a script's reflection chapter in the self-improvement loop. `explainer run --reflection deposit` writes `reflection.md` beside the export and files one owner-queue deposit, keyed by script id and script sha so a re-run files nothing twice; `--reflection retro-file` writes a dated retro file instead, and the default `off` writes nothing. `--asker` names the seat that asks.
