`shepherd register` takes `--head` and `--base`. With `--branch` and `--head` it trusts the branch and does not read the pull request from GitHub. The registration stores the head and base (store migration 24), and Shepherd classes the PR's G10 hold, its review panel and its reviewer's size from `git diff --name-status -M <base>...<head>` in its git cache, cached by head. A registration with no base, or a head git cannot fetch, still reads GitHub's file list.
