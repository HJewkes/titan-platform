The resolve stage stores the template fill's generated slots as its `slots` artifact when no pin supplies one, so the emphasis-target gate now runs on every new resolve, and it adds a `template-fill` gate that fails on a refused beat and lists fallbacks. Compare element ids are numbered per label (a row's `id` and its new optional `alias`), matching the cue words scripts use, and a list drawn untitled because its chapter label is too long carries `hints.titleOmitted`. Resolve's stage version moves to `p5f2`.
