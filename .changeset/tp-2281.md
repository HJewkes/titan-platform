The installed-profile guard follows `AGENT_CHAT_HOME` (else `$HOME/.agent-chat/profiles`), refuses a profile name outside `^[a-z0-9][a-z0-9._-]*$` before building a path, and `agentChatEnv()` forwards a non-empty `AGENT_CHAT_HOME` so the CLI reaches the broker whose profiles were checked.
