Read a git push that moves a tag as `release` (`bash.release.git-push-tag`): `--tags`, `--follow-tags`, a refspec whose destination is `refs/tags/…`, `tags/…` or a `v<digit>` name, and `tag <name>`. Branch-push verdicts are unchanged and still reported beside it.
