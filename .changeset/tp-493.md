`titan-factory serve` broadcasts versioned `shepherd` frames on `/events` (`{v:1,kind,repo?,pr?,runId?,stepId?,at}`) from host workflow events, Shepherd registration writes and a `PRAGMA data_version` poll that marks another process's commit `external`, coalesced 250 ms per run (TP-493). `ShepherdStoreRef` gains an optional `onChange`.
