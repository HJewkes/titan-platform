Shepherd's CI-policy merge guard sorts a weakened line into a budget class and a weakening class (TP-4760, owner decision 552). A diff whose every changed path is a read `.github/` workflow or `.github/ci-budget.json`, each judged by its parsed structure (a workflow's trees equal once job and step `timeout-minutes` are masked, with a timeout only moved, or added where GitHub reads one; the budget file only moving numbers or adding entries; any other file kind reads as a weakening), which keeps every required check present, under a reviewer MERGE given at that head and with a GitHub Actions run of the same repo linked in the PR body, gates on the new `shepherd-merge-guard/ci-policy-budget` row. That gate carries no D21 owner-at-head marker, and `titan-factory gate resolve` admits a coordinator on it with the same fresh merge evidence as a mechanical MRG-AU gate. Every other weakened line, and any evidence stored before this release, stays on the owner-only `ci-policy-weakened` row.
