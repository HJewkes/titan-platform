The script stage runs resolve's template fill on its own draft, with no slots pin and no code, and leaves code and companion beats to resolve. Each beat the fill would refuse, such as a list of 7 labels against the slot schema's 5 rows, is a plan fault: the plan retry names it, its hint asks for the rest of the labels to move to a continuation beat in the same chapter, the chapter reader counts it, every L0 repair round answers it as a `template-fill` row, and a new `template-fill` gate fails what is left. A rewrite round reverts a beat whose appended labels make the fill refuse it, as `template-fill`. The script stage version moves to x11 and the rewrite stage version to x6.
