A number shown bare on screen that equals a PR or task id the beat cites is a citation, not a fact the narration must say. qa's narration-facts gate, the Q-D14 L0 row and the rewrite guard's `number-lost` check all read it that way, so a rewrite may take such an id out of the spoken line. A real number (a count, a duration, a percent, or a quantity that happens to equal an id) must still be spoken.
