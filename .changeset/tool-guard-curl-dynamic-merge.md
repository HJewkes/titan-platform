curl, wget and httpie sending a write method to a URL whose host, or whose `api.github.com` path, is known only at run time now classify as `bash.merge.curl-api {}` (TP-2728 b). The request reader fails closed: a run-time or lower-case httpie method, a write in any `--next` request, a URL it cannot see (xargs, `wget -i`, none given) and a globbed or `--expand-url` URL all count as run-time. curl options are read against curl's full option list: `--expand-<opt>` reads as `<opt>` with `{{var}}` run-time, `--no-<switch>` turns a switch off (last wins), and an unknown option, `-K` or `--request-target` makes the method and URL unknown. A short cluster's `:` (`-s:`) starts a new request like `--next`, and for curl and wget a run-time word that may be an option (it splits, as `$A`, `"$@"` or `"${A[@]}"` do, or nothing but a `-` precedes its run-time part) leaves the request unknown when it splits or another word follows it. wget options are read against wget's full option list with getopt_long prefixes expanded (`--meth`); `-e` method and body commands set the method, and any other `-e` command, a run-time one, an unknown option or `--config` leaves the request unknown; `-e` robots, tries, timeout and wait are read as no-ops. A line that may choose or write the config file curl, wget or httpie reads leaves every request on it unknown: it writes WGETRC, SYSTEM_WGETRC, CURL_HOME, XDG_CONFIG_HOME, HOME or HTTPIE_CONFIG_DIR in any form the variable tracker reads (prefix, `${NAME:=…}`, `export`, `declare`, `read`, `for`, `mapfile`, `printf -v`, a nameref, arithmetic, or a run-time name in any of them), names a wgetrc, curlrc or httpie config path, or may write a file whose literal part does not rule out an rc file: an output redirect (zsh `>!` included), a curl, wget or httpie output option, or any operand or glued value (`of=`, `-o…`) of a command outside a short read-only list. After a `cd` or `pushd` to the home, `~/.config`, httpie or `/etc` directory, or to a run-time one, any command outside that list (an unpacker such as `tar xf`) counts as writing an rc file.
