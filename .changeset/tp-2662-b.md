An autonomy-seat/v1 seat file may declare `visual_baselines: { check, paths }` beside `visual_paths`, and `Seat` carries it as `visualBaselines`. The seat book refuses it without `visual_paths`, with an empty `check`, or with a baseline glob that matches no repo-relative path (the message names `visual_baselines`). A remote several seats share keeps it only when every seat with visual paths declares the same check and paths. Nothing reads it yet (TP-2662).
