`shepherd.visualThreshold` accepts mode `on`, and under it the merge decides on the measured visual delta (TP-4320 S4). A public API report, a token path or a visual harness path gates on row `visual-path` whether or not a seat glob matched it; so do a snapshot above `maxChangedShare` (naming its component and share), a removed snapshot, an unmeasured one and a delta that fails its schema. A changed baseline measured at or below the threshold, or an added snapshot, no longer gates, and the allow names how many snapshots changed and the largest share. Any other changed baseline, and a red or missing baseline check, gate as before. Under `shadow`, `off` or with no delta the decision is unchanged.
