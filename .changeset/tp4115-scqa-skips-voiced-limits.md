Q-F12 (voiced simplifications and limits) no longer gates a `daily-overview` script: the daily briefing reports a day and has no simplified model. Every other type is still held to it, including a paper-summary, pr-overview or repo-argument script that picks `scqa`. L0 rules can now name `except_profiles`, so a structure or type added later stays gated by default.
