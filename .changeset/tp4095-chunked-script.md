Draft and repair long scripts one chapter per call: a spine with more than 8 chapters or 40 ledger beats gets a draft call per chapter with the shared context and what is written so far, repairs on the `scope: chapter` rules per chapter, then one whole-video repair round on the joined script. Rules in `rules.yaml` may now declare `scope: chapter`; the run report notes each chapter's calls and dollars.
