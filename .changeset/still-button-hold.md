The still seed now holds any still cue-less beat (a button, an outro, or a claim-card with no cue) while the held band has room, and the script stage applies that hold to each repair reply too, so a reply that shortens a button's label no longer leaves it still. The Q-D20 hint for an unheld button or outro names the hold, built from the split hint's rule table; once the held band is full, it and the Q-D22 hint lead with a label the voice does not read word for word instead. A repair reply that ties its base on rows and beats under other rules is now the next round's base. The script stage version moves to x31.
