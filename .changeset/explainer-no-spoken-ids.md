A daily says no pull request, task or script id aloud. The script prompt and planner guide name a change by what it did and leave the id to the screen; the new Q-V15 L0 row fails a spoken id in digits or in words; the rewrite guard lets an id leave the line (no `new-term`, `entity` or `terms` refusal for it) but refuses one it cuts short or adds (`id-changed`), and still refuses a lost real number or term. The ledger stamp reads a handle shown on screen as well as one spoken.
