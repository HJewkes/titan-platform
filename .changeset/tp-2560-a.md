`register` takes `abandonsOrphan`: when a workflow returns, a recovered step its replay never reached is dropped with a new `step_abandoned` event if the predicate allows it, instead of parking the run as `recovery_required`. Without the predicate such a run still parks, now with the evidence `replay never reached recovered step <id>` (TP-2560 a).
