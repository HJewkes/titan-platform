`task done` now names the open tasks it unblocks, in any initiative, as a `completing X unblocks A-1, B-2` warning and a ` (unblocks A-1, B-2)` suffix on the `--quiet` line. An agent caller gets a count for dependents in initiatives it may not see. The JSON task result is unchanged.
