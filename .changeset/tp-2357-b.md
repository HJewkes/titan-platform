sh-fix-proof trusts a result line only from a fix-proof run that concluded success on a PR that leaves the harness (workflows, actions, fix-proof.json, scripts/fix-proof-run.sh) alone; anything else is recorded as untrusted, so the reviewer brief gets no proof and a vacuous line cannot end the review as NO_REPRO. The newest fix-proof run at the head is always the one read.
