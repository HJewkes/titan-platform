The rewrite pass now takes every spoken PR, task or script id out of a line, even after the register bands are met. The plan directs each beat that says an id, whether or not a register row fails. A chapter that only cuts ids is kept as long as it moves no further from band. Rounds keep running while Q-V15 still finds an id.
