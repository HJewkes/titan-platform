# @titan-design/explainer

## 0.3.0

### Minor Changes

- 72b0a1e: Q-D7 assertion headlines (TP-4328). Every beat's `visual.assertion` must be a claim, a subject and a finite verb in at most ten words, and when the beat carries `authored` it must be written before the narration. The verb test reads speech-g2p's part-of-speech tags, so it costs no model call. Failing rows get a repair hint naming each defect. A new `talks-ST11` craft line tells the planner to plan each headline first, and the planner guides carry it.
- dfcb141: `eval cold` now scores a roll call's bare items in code. A list beat of three or more items, at least half of them spoken without one gloss word in any clause of the chapter, has each bare item scored 0 (`named only in a list`), whatever the viewer answers. A single bare item among glossed siblings is still graded from the answer. Cold questions also ask "what is X?" (kind `spoken-term`) for each `video.glossary` name and each spoken identifier such as `F7`, at the beat that first speaks it, unless a new item's label at or before that beat already names it. An unexplained spoken term counts as an undefined item. `ColdInput` takes an optional `glossary`, read from both spike and script/v1 files. The eval_version changes.
- b4bbc0d: `eval cold` scores reader gaps from the spoken words only (TP-3807). Both cold prompts now show each beat's spoken words and end, never the on-screen labels, since the reader-gap labels come from readers who had the narration only. Spoken terms are asked "what does X mean here?" in a call of their own per chapter, under the new rubric `l1-cold-spoken.md`, which does not count a sentence that only uses the word as a definition; that call has its own canary. A term inside a longer new label ("I2 verdict at head") is now asked on its own. `ColdChapter.canary` becomes `canaries`, one a call. `playbackTranscript` is renamed `spokenTranscript`. The new `readerGapScores` scores each labelled reader-gap group at its items' first questions, and `eval cold --labels <file>` prints it per run. Viewer-agreed terms are asked as `viewer-term` questions, and their zeros go to new `undefined_terms` and `undefined_terms_per_minute` columns, not `undefined_items`, so the chapter bars stay comparable with earlier runs; `cold-chapters.tsv` gains those columns, so write to a fresh bench. The eval_version changes.
- 2590789: `eval cold` now asks about the spoken terms that cold viewers cannot define. Before the scoring runs, three fresh viewers each read the whole video's playback (rubric `l1-cold-terms.md`) and list the terms they could not define from it. A term is kept when at least two of the three runs name it, with case and plurals folded together. It is asked in the form the narration first speaks, at its first spoken beat, as a `spoken-term` question. The pass writes an `L1-cold-terms` run record holding its spend. If a terms call fails, the command exits 1. `coldTerms` is exported. The eval_version changes. The `paceBeats` wrapper is removed; use `paceInput(...).beats`.
- 6eb3dd6: A repo run's companion links now resolve end to end. Export links the `companion` artifact into the theater folder as exactly `companion.md`, beside the video, whether or not `bridge.json` lists it, so the relative `companion.md#<anchor>` hrefs open the right section. The resolve stage version changes to `pp7` and the run workflow version to `tp4107`.
- 78635e6: A custom layer that fails the compile gate gets one repair round through agent-chat. Repairs run only when the host passes a `layerRepairer`; they turn on by default after TP-2608 ships the TSX `beat-builder` profile.

- 072f0ce: The `audition` stage now samples, scores and picks (TP-4010, PP-8).
