## Questions that read the story spine

This script was planned against a story spine. Some questions quote what the spine declares.
Treat each declaration as the writer's claim to check, not as a fact.

- **Kind honest** ("the spine ledger declares ... which item is not the kind of thing it is
  declared to be?"). A step is an action the system takes; a property is a quality it has; a
  constraint is a fact it must live with; an invariant is a rule it must keep; a part is a
  component; a number is a quantity. Set `odd_one_out` to the label, exactly as listed, of an
  item that is not the kind declared for it, or null if every item is. Set `pass` to true when you
  pick none. Quote the beat that lists the items. The rule that `odd_one_out` is null outside an
  odd one out does not apply to this question.
- **Seated in a named part** ("the spine says P keeps it"). Answer as for Seated, and set `pass`
  to true only if the map's labels show P or the mechanism the beat states.
